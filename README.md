# Vũ Trung Sơn

Tôi viết phần mềm Windows giải quyết việc văn phòng thường gặp: bật macro Excel bị chặn,
kiểm tra USB dung lượng ảo, cài .NET SDK không cần quyền Administrator.
Tất cả sản phẩm bán tại cửa hàng của tôi: https://sonvudev.com

## Sản phẩm

- **Excel Trusted Locations Setup** — bật macro Excel bị chặn, thêm thư mục vào
  Trusted Locations, có dry-run và hoàn tác, không cần quyền Admin:
  https://sonvudev.com/product/excel-trusted-locations-setup
- **Spark Capacity Tester** — kiểm tra dung lượng thật của USB, phát hiện USB ghi
  khống dung lượng, đo tốc độ đọc/ghi, báo PASS/FAIL:
  https://sonvudev.com/product/spark-capacity-tester-pro
- **.NET SDK Portable Updater** — cài .NET SDK portable trên máy không có quyền
  Administrator, tự đặt DOTNET_ROOT và PATH:
  https://sonvudev.com/product/dotnet-sdk-portable-updater
